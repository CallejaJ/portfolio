# Referido artistas — código NITRILE50

Campaña de lanzamiento para llenar portfolio de artistas. Nitrile Affair comparte su código y sus contactos consiguen un 50% de descuento en el **paquete básico** (99€ en vez de 199€).

## Cómo funciona (para Jorge)
- El enlace `jorgecalleja.dev/musicos?ref=nitrile` ya muestra el 50% aplicado, el precio 99€ y precarga el código en el botón de WhatsApp.
- Cuando alguien te escriba con **NITRILE50**, sabes que viene de Nitrile. Aplica 99€ al paquete básico (una página: música, vídeos, bolos, galería, contacto · 1 ronda de cambios). Extras (tienda, más páginas, dominio) se cotizan aparte.
- Mantén el tope: plazas limitadas / oferta de lanzamiento, para que el 99€ no se vuelva el precio de siempre.
- Acordado con Nitrile: define qué gana él por cada web cerrada (comisión, mantenimiento gratis, etc.).
